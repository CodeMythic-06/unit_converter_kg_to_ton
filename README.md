# Kilograms to Metric Tons Converter

A simple, interactive Python command-line tool that converts weight from kilograms (kg) to metric tons.

## Features
* **Easy to use**: Enter a number and get the result instantly.
* **Input check**: Prevents negative numbers and stops text errors.
* **Precise**: Shows results up to four decimal places.

## How to Run It

### Prerequisites
Make sure you have **Python 3** installed on your computer.

### Steps
1. Download the code file (for example, `converter.py`).
2. Open your terminal or command prompt.
3. Run the script with this command:

```bash
python converter.py
```

## How It Works
The program uses a basic math formula:
* **Formula:** `Tons = Kilograms ÷ 1000`

## Example
```text
--- KG to Metric Tons Converter ---
Enter weight in kilograms (kg): 2500
2500.0 kg is equal to 2.5000 tons.
```
